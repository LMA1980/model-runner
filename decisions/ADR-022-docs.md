# ADR-022: Docs

**Status**: Locked

## Context

The 1000-character limit dropped rationale and let contradictions creep in.

## Decision

Keep the 1000-char limit for `features/` and `specs/`. `decisions/` (ADRs) and `user-story/` (business assertions and specification references) are exempt from it.

## Consequences

Feature/spec docs stay normative summaries linking to ADRs and User Stories.
